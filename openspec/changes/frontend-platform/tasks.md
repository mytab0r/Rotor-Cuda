# Tasks — frontend platform

Phases from `proposal.md`. Each phase lands as its own PR; the split must never
ship two renderers for the same route.

## 0. Skeleton

- [ ] `web/` Astro app: pinned deps, committed lockfile, `npm ci` in CI, area in
      `projects.json`.
- [ ] `data/chains.json` and `data/puzzles.json` consumed by both Rust and Astro
      (one source, generated or imported). `data/puzzles.json` now mirrors the
      `PUZZLE_TARGETS` table in `src/coordinator/puzzles.rs`, and
      `web/tests/puzzles.test.ts` fails when the two drift; the coordinator
      still reads its embedded array until the cutover.
- [ ] CSP plan and provider allowlist documented before any page moves.

## 1. Pilot

- [ ] `/mnemonic-converter` on Astro (islands only where needed).
- [ ] Acceptance: route JS <= 45 KB gzip, `ui-audit` 0 violations, LCP <= 1.5 s,

- [ ] Sitemap/robots generated by Astro; counts match 18 chains.

## 6. Cutover

- [ ] Cutover gate: every rewritten pattern in `data/routes.json` is served by
      its target renderer and no `live` row still points at the coordinator for
      a migrated route family.
- [ ] Pages serves the whole `web/dist` tree, including `a/<sha>/`; the
      prerendered HTML, sitemap and `og:image` URLs depend on those immutable
      asset paths.
- [ ] Pages needs a `_headers` CSP whose `connect-src` carries the same
      provider allowlist the coordinator sets today.
- [ ] Origin switch: Pages/Functions serve HTML, Rust serves `/api/v1/*` only.
- [ ] Rust HTML routes return 410; `include_str!` HTML removed.

## 8. Browser regression gate

- [x] Pin `@playwright/test` and `@axe-core/playwright` as dev dependencies of
      `web/`; no runtime dependency is added to the site.
- [x] `web/playwright.config.ts` runs 375×812, 768×1024 and 1280×900 in light
      and dark against `web/dist` served locally by
      `web/scripts/serve-dist.mjs`, with no network access and one retry.
- [x] E2E contract for the twelve routes the static build owns: exact title and
      H1, expected table rows, no document horizontal overflow, one narrow nav
      toggle, menu open and Escape close.
- [x] Axe scan on every route and project; critical and serious findings fail
      the build, with no allowlist. The first run's real findings (in-text link
      distinction, light-theme address contrast, focusable docs code blocks)
      are fixed in the shared source.
- [x] Visual baselines under `web/tests/__screenshots__/`, footer build id
      masked, 2% cross-platform pixel tolerance; `npm run test:e2e:update`
      rewrites them deliberately.
- [x] CI job builds, serves, runs Playwright and uploads the HTML report and
      failure diffs; a hidden-column mutation was caught by the visual gate and
      reverted.
