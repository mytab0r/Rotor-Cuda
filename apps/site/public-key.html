Cabinet

Public key to addresses

Paste a secp256k1 public key and see every address it controls. A public key cannot be turned back into a private key, so this page never asks for one.

secp256k1Runs locallyNo private key

Public key

Accepts the 33-byte compressed form (02/03 prefix) and the 65-byte uncompressed form (04 prefix). Points that are not on the curve are rejected. The key and the results stay in this tab.

Key facts

Addresses

P2PKH and P2SH use the compressed key. The uncompressed P2PKH row is shown because old wallets derived legacy addresses that way.
