Transaction decoders

Paste a raw transaction and read its structure. The bytes are decoded in this tab; nothing is sent to a server and no private key is involved.

Bitcoin transaction decoder Legacy or SegWit hex to version, inputs, outputs, script types, addresses, locktime, size, weight and virtual size. A fee needs prevout values. RAW HEX → LEGACY · SEGWIT Ethereum transaction decoder Legacy, EIP-2930 and EIP-1559 hex to chain id, nonce, gas, fees, destination or contract creation, value, data and access list. RAW HEX → TYPE 0 · 1 · 2

What gets decoded

  • Bitcoin: version, SegWit marker and flag, every input (txid, vout, scriptSig, sequence, witness), every output (sats and BTC, script type, address when one exists), locktime, serialized size, weight and vsize.
  • Ethereum: EIP-2718 type, chain id, nonce, gas price or max priority/max fee, gas limit, destination or contract creation, value in wei and ETH, data length, selector, first bytes, access list, y-parity or v, r and s.
  • No invented fields. A Bitcoin fee is shown only when you supply one satoshi value per input. Signature recovery and verification are not performed, and malformed hex is rejected with the byte offset.

The JSON view contains the full report. Copy buttons are local clipboard actions only; there is no upload, storage or URL payload.
