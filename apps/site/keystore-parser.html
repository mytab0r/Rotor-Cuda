Cabinet

Ethereum keystore parser

Paste a V3 UTC/JSON keystore and its password to recover the address. Decryption runs in this tab; the file and password are never uploaded, stored or logged.

V3 keystorescrypt / PBKDF2Runs locally

A keystore password unlocks real funds. Use this page offline for a live wallet, and close the tab afterwards; the fields are cleared when you leave.

Keystore

Supported: version 3 with aes-128-ctr, KDF scrypt or pbkdf2 (HMAC-SHA256), 32-byte derived key. The keystore JSON is validated in the page; unsupported fields produce an explicit message instead of a guessed result.
