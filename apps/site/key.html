Formats and behaviour

Derives automatically as you type: 64 hex characters (optional 0x), a decimal integer, a Bitcoin WIF, a Solana keypair JSON array, or any other text as a brainwallet phrase (key = SHA-256 of the text). The key stays in memory only and is cleared when you leave the page.

Use only keys you control. If a key holds funds, keep it offline or air-gapped — this page never asks for a seed phrase.

Total value prices the loaded balances from a public ticker cached for up to six hours; rows without a price or a balance are excluded.

A key in the page URL is already exposed to browser history and server logs. On /key/<key> the derived public addresses are checked once against the Crypto registry so a registered owner can be warned; the key itself never leaves this page.
