Private-key explorer

Every private key is a number. See what yours opens — all derivation happens in this browser.

Use only keys you control. If a key holds funds, keep it offline or air-gapped — this page never asks for a seed phrase.

Key input

This key is in the page URL. The derived addresses are checked against the Rotor registry so a registered owner can be warned; the key itself stays in this browser.

Accepts 64 hex characters with an optional 0x prefix, a decimal integer, or a Bitcoin WIF. The key stays in memory only and is cleared when you leave the page.

Sends the derived addresses (never the key) to the coordinator so a registered owner can be warned that someone looked them up.
