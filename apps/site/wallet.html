Wallet Cabinet

Cabinet wallet

Keep WIF and hex keys in an encrypted vault on this device and watch the addresses they control. The vault is encrypted with a passphrase you choose; the server never receives the passphrase, a private key or a WIF.

Local vaultPBKDF2 + AES-GCMWatch-only until you signSepolia EVM sendEVM mainnet (armed per session)Bitcoin testnet send

The vault lives in this browser's IndexedDB. Losing the passphrase loses the keys: there is no recovery and the server cannot help. Export an encrypted backup and keep it somewhere safe. EVM keys can send native coin and ERC-20 tokens on Ethereum Sepolia and, after you arm mainnet for the session, on Ethereum, BNB Chain, Arbitrum, Optimism, Base, Polygon, Avalanche and zkSync. Bitcoin keys can send on Bitcoin testnet. The page builds and reviews the transaction, signs it locally in WASM and broadcasts the signed raw transaction directly to a public provider. This phase covers native-coin transfers and the ERC-20 transfer(address,uint256) method only; token approvals, other token methods and Bitcoin/TRON mainnet are not part of it. Per-transaction fee caps: 0.05 ETH on Ethereum mainnet and 0.01 native on every other mainnet chain.

Create a vault

Use at least 8 characters. The passphrase derives the AES key with PBKDF2-SHA256 (600,000 iterations); it is kept only in memory while the vault is unlocked.

Unlock the vault

A wrong passphrase cannot decrypt anything. The vault locks itself after 10 minutes without activity and whenever this page is hidden.

Import a key

A WIF is checked and mapped by its version byte: Bitcoin mainnet compressed WIFs use native SegWit and uncompressed ones use legacy P2PKH, Bitcoin testnet WIFs (version 0xEF) use testnet native SegWit (tb1), Litecoin uses native SegWit and Dogecoin uses legacy. Dogecoin testnet (0xF1) is not supported. Any 64-character hex key needs an explicit chain; choose Bitcoin testnet to derive a tb1 address. The address is derived with the local WASM core first (testnet through derive_report_network); a key whose address cannot be derived is not stored.

Generate a seed phrase

Word count

12 words · 128-bit entropy · generate or paste a phrase

128 bits is 3.4×10^38 keys. At 10^12 guesses per second that is about 1.1×10^19 years — roughly 780 million times the age of the universe. A 24-word phrase is 256 bits (about 3.7×10^57 years).

The phrase is generated and shown in this tab only; it is never stored, sent or logged. The vault stores only the derived key for one chain, with the default BIP44 path of the selected chain. Zcash, Solana, Sui and TON have no BIP44 preset here: import a WIF or hex key for those chains instead.

Send an EVM transaction

The transaction is built from this form, reviewed field by field, signed in this tab by the local WASM core and then broadcast as a signed raw transaction. Public reads and the broadcast go directly from this browser to the chosen public RPC with the browser's real Origin; the server never sees a key and does not proxy these requests.

Select a key to see its EVM address.

Sepolia is the default. A mainnet network is only signable after you tick the arm checkbox; the arm resets when the vault locks or unlocks and on page reload. The chain id is read with eth_chainId before review and again before signing; a mismatch, or an id outside the wallet chain table, refuses the send. Leave the token contract empty to send the native coin. A filled contract must return code, report 0–24 decimals and a printable symbol of at most 32 characters, and hold at least the amount; the wallet reads decimals(), symbol() and balanceOf() and builds transfer(address,uint256) locally. Approvals and other token methods are not part of this slice. The per-transaction fee cap is 0.05 ETH on Ethereum mainnet and 0.01 native on the other chains.

Empty gas limit uses eth_estimateGas; mainnet adds a 20% buffer. Empty fees use the node's priority fee and 2 × base fee + priority. On mainnet a native send's amount plus the maximum network fee, or a token send's maximum network fee and nothing else, must fit the native balance, and the network fee must stay under the chain cap, or the send is refused before signing. Editing any field after a review hides it, so the signature always covers exactly what was reviewed.

      What is stored

      IndexedDB database rotor-wallet, store vault: one versioned record with a random 16-byte salt, PBKDF2-SHA256 with 600,000 iterations, AES-GCM-256 and a fresh 12-byte IV on every save. The record holds only ciphertext; the passphrase and the keys are never written to localStorage, the URL, logs or the network.

      This page can sign and broadcast EVM transfers on Sepolia and, after you arm mainnet for the session, native-token transfers on eight EVM mainnets, plus Bitcoin testnet transactions. The signatures and the raw transactions are created in this tab; only signed raw transactions are sent to public providers. Watch-only still means address display and opt-in balances without signing.
