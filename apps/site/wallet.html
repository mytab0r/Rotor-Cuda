Wallet Cabinet

Cabinet wallet

Keep WIF and hex keys in an encrypted vault on this device and watch the addresses they control. The vault is encrypted with a passphrase you choose; the server never receives the passphrase, a private key or a WIF.

Local vaultPBKDF2 + AES-GCMWatch-only until you signSepolia EVM sendBitcoin testnet send

The vault lives in this browser's IndexedDB. Losing the passphrase loses the keys: there is no recovery and the server cannot help. Export an encrypted backup and keep it somewhere safe. EVM keys can send on Ethereum Sepolia and Bitcoin keys can send on Bitcoin testnet: the page builds and reviews the transaction, signs it locally in WASM and broadcasts the signed raw transaction directly to a public provider. Mainnet signing stays disabled in this phase.

Create a vault

Use at least 8 characters. The passphrase derives the AES key with PBKDF2-SHA256 (600,000 iterations); it is kept only in memory while the vault is unlocked.

Unlock the vault

A wrong passphrase cannot decrypt anything. The vault locks itself after 10 minutes without activity and whenever this page is hidden.

Import a key

A WIF is checked and mapped by its version byte: Bitcoin mainnet compressed WIFs use native SegWit and uncompressed ones use legacy P2PKH, Bitcoin testnet WIFs (version 0xEF) use testnet native SegWit (tb1), Litecoin uses native SegWit and Dogecoin uses legacy. Dogecoin testnet (0xF1) is not supported. Any 64-character hex key needs an explicit chain; choose Bitcoin testnet to derive a tb1 address. The address is derived with the local WASM core first (testnet through derive_report_network); a key whose address cannot be derived is not stored.

Send an EVM testnet transaction

The transaction is built from this form, reviewed field by field, signed in this tab by the local WASM core and then broadcast as a signed raw transaction. Public reads and the broadcast go directly from this browser to the chosen public RPC with the browser's real Origin; the server never sees a key and does not proxy these requests.

Select a key to see its EVM address.

Only Sepolia is enabled. Mainnet signing stays off until the testnet flow is verified end to end. The chain id is read with eth_chainId before review and again before signing; a mismatch refuses the send.

Empty gas limit uses eth_estimateGas; empty fees use the node's priority fee and 2 × base fee + priority. Editing any field after a review hides it, so the signature always covers exactly what was reviewed.

      What is stored

      IndexedDB database rotor-wallet, store vault: one versioned record with a random 16-byte salt, PBKDF2-SHA256 with 600,000 iterations, AES-GCM-256 and a fresh 12-byte IV on every save. The record holds only ciphertext; the passphrase and the keys are never written to localStorage, the URL, logs or the network.

      This page can sign and broadcast Sepolia EVM and Bitcoin testnet transactions only after the review screen. The signatures and the raw transactions are created in this tab; only signed raw transactions are sent to public providers. Watch-only still means address display and opt-in balances without signing.
