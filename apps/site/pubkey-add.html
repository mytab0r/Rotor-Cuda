Public key arithmetic

Compute P + Q, P − Q or k · P on secp256k1. The result is another public key, shown in both compressed and uncompressed form.

secp256k1Runs locallyNo private key

Points

P + Q adds two public keys. Each input accepts a 66-hex compressed or 130-hex uncompressed public key.

For P ± Q each input accepts a 66-hex compressed or 130-hex uncompressed public key. For k · P the second input is a 32-byte big-endian scalar in the range 1 to n−1. Points off the curve are rejected, and so is a result that lands on the point at infinity (for example P − P), because that value has no serialized public key.
