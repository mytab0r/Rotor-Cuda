Run a browser worker

This tab leases one chunk at a time from the coordinator and scans it in WebAssembly. It reports progress every few seconds and submits a result only when the wasm scanner finds a key. The rate shown below is measured in this tab, not a promise: a browser is a small volunteer contribution next to the GPU client.

Authorized puzzle jobs only. This page never accepts a target you type: it can only lease jobs that the coordinator operator has already created, and it submits results through the same verified protocol as the native client.

This page needs a secure context (HTTPS or localhost) before it will start the worker.
