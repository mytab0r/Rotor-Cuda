Rotor Coordinator

A community puzzle solver. Clients lease disjoint key ranges from this coordinator, scan them on CPU or GPU, and report accepted completions. Everyone's work is verified, counted and shown on the leaderboard.

Paste a 64-hex private key to open its key page. WIF and addresses are handled in the key calculator.

How it works

  1. Register here (when open) or ask the operator for a token.
  2. Run rotor with --coordinator and --token; it leases a key range.
  3. The client scans and sends heartbeats plus a verified completion sample.
  4. The coordinator counts accepted work and ranks every contributor.

Read the docs for CPU/GPU commands and the puzzle-only disclaimer.
