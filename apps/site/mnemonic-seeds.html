Mnemonic seed directory

Select a chain above to enumerate deterministic English BIP39 phrases, 60 per page. Each page can use 12, 18 or 24 words (128, 192 or 256 bits of entropy), a standard or custom BIP32 derivation path, and the chain's address types.

The seed index is converted to entropy with BigInt arithmetic, so pages are reproducible but never stored. Phrases, keys and addresses are derived in this browser; the only network calls are public balance lookups for the derived addresses.

  • Seed phrase converter — derive addresses from one phrase you already have.
  • Private key directory — browse the raw key space instead of mnemonics.
  • Key calculator — inspect one hex, decimal or WIF key.

These are deterministic example phrases, not a wallet and not a recovery service. Finding a funded seed by enumeration is infeasible. Use the tool for education, testing and seeds you control.
