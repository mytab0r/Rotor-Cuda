Private-key explorer

Every private key is a number. See what yours opens — all derivation happens in this browser.

Use only keys you control. If a key holds funds, do not type it into an online page — prefer an offline or air-gapped machine. This page never asks for a seed phrase.

Nothing is sent anywhere unless you turn on balance lookups and press "Check balances". The private key itself never leaves this page.

Key input

Accepts 64 hex characters with an optional 0x prefix, a decimal integer, or a Bitcoin WIF. The key stays in memory only: it is not written to the URL, history or storage, and it is cleared when you leave the page.
