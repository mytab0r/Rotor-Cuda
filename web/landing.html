How it works

  1. Register here (when open) or ask the operator for a token.
  2. Run rotor with --coordinator and --token; it leases a key range.
  3. The client scans and sends heartbeats plus a verified completion sample.
  4. The coordinator counts accepted work and ranks every contributor.

Read the docs for CPU/GPU commands and the puzzle-only disclaimer.
